## 📋 About

**Vinvelil Oru Payanam 2.0** (*"A Journey Into Space 2.0"*) is the official event website for **IARRD's** astronomy workshop, covering sessions on Time Travel & Relativity, The Multiverse Theory, and Orbital Mechanics. The site opens with a fully animated 3D solar system as its hero backdrop, alongside a live countdown to the event, registration, and a secure payment gateway.

## ✨ Features

- 🌌 **Cinematic 3D Hero** — an animated, orbiting solar system built with Three.js, complete with fog, tone-mapped lighting, and a starfield
- ⏳ **Live Countdown Timer** to the event date
- 📚 **Mission Files** — session showcase (Time Travel & Relativity, The Multiverse Theory, Orbital Mechanics)
- 👥 **Mission Control** — team section featuring Leadership and Domain Team Leads
- 📝 **Registration Flow** with a dedicated success page
- 💳 **Secure Payments** via Razorpay (order creation + signature verification)
- 🔐 **Admin Panel** for managing registrations
- 📞 **Contact Section** — general inquiries, WhatsApp support, and social links
- 🎵 Ambient background audio for an immersive experience
- 🗣️ Bilingual branding (Tamil + English)

## 🛠️ Tech Stack

**Frontend:** HTML5, CSS3, vanilla JavaScript, Three.js
**Backend:** Node.js, Express, Razorpay SDK
